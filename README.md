# 🛡️ EMIGuard

## 💰 EMI Budget Stress Analyzer

EMIGuard is a beginner-friendly C project that analyzes monthly income, expenses, and a proposed EMI to estimate the remaining monthly budget and financial stress level. 📊💳

---

## ✨ Features

- 💰 Monthly income input
- 🛒 Monthly expense input
- 💳 Proposed EMI analysis
- 💵 Remaining balance calculation
- 📊 Budget utilization percentage
- 🟢 Low Risk indicator
- 🟡 Moderate Risk indicator
- 🔴 High Risk indicator
- 🎨 Colored terminal interface
- 🛡️ Basic financial budget analysis

---

## 🛠️ Technologies Used

- C Programming
- GCC Compiler
- Visual Studio Code
